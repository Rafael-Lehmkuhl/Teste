## Como transformar em PowerPoint

1. Abra o `.md` no Cursor, VS Code ou qualquer editor
2. Copie o conteúdo de cada **Slide N** para um slide no PowerPoint/Google Slides
3. Ou use ferramentas como [Marp](https://marp.app/) ou [Slidev](https://sli.dev/) para converter Markdown → apresentação
